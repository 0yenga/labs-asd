# Лабораторная работа №3

## Задача 1. Рекурсия. Бинарные деревья

Дано бинарное дерево. Найти поддеревья с максимальным и минимальным отношением
`высота / число листьев`.

Высота считается в вершинах: лист имеет высоту 1. Для каждого поддерева
выводятся корень, высота, число листьев и само отношение.

## Ввод

Сначала `N`, затем `N` строк вида `значение left right`.
`left` и `right` — номера дочерних вершин (`0`, если вершины нет).
Корень имеет номер `1`.

```text
9
1 2 3
2 4 5
3 6 0
4 0 0
5 7 8
6 9 0
7 0 0
8 0 0
9 0 0
```

## Запуск

```bash
javac -encoding UTF-8 -d out src/*.java
java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt
```

В PowerShell:

```powershell
cmd /c "java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt"
```

## Идея решения

Высота и число листьев поддерева рекурсивно вычисляются через левое и правое
поддеревья. Затем дерево обходится ещё раз: для каждой вершины вычисляется
отношение, находятся максимум и минимум, после чего выводятся все поддеревья
с этими значениями.

Готовые коллекции JDK не используются, только массив вершин и ссылки `left`/`right`.
