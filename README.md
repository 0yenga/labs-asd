# Лабораторные работы по АСД

Лабораторные работы по дисциплине «Алгоритмы и структуры данных».

## Состав

```text
lab1/, лабораторная работа №1: списки, стеки, очереди (задача 1)
lab2/, лабораторная работа №2: разреженные матрицы (задача 1)
lab3/, лабораторная работа №3: бинарные деревья (задача 1)
lab4/, лабораторная работа №4: N-деревья (задача 1)
lab5/, лабораторная работа №5: хэширование, вариант 1
lab6/, лабораторная работа №6: методы сортировки (задача 1)
```

Каждая работа собирается и проверяется независимо, инструкция находится в README внутри папки.
