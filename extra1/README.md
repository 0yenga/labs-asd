# Дополнительная лабораторная работа №1

## Задача 1. Рекурсия и головоломки. Какуро

Какуро — числовая головоломка, математический аналог кроссворда. Поле состоит
из чёрных, белых и клеток-подсказок. В белые клетки нужно вписать цифры от 1
до 9 так, чтобы:

- в пределах одного отрезка строки или столбца цифры не повторялись;
- сумма цифр в отрезке справа от подсказки равнялась верхнему правому числу;
- сумма цифр в отрезке снизу от подсказки равнялась нижнему левому числу.

Отрезок заканчивается перед чёрной клеткой, клеткой-подсказкой или краем поля.

## Ввод

Сначала `rows` и `cols` — размеры поля. Затем `rows * cols` токенов:

| Токен | Значение |
| --- | --- |
| `#` | чёрная (неактивная) клетка |
| `.` | пустая белая клетка |
| `r/c` | подсказка: `r` — сумма по строке, `c` — сумма по столбцу |
| `0` или `-` | соответствующей суммы нет |

Пример `input.txt`:

```text
5 5
# # 0/10 0/2 #
# 3/4 . . #
7/0 . . # #
6/0 . . # #
# # # # #
```

Здесь `3/4` означает: сумма по строке равна 3, сумма по столбцу равна 4.

## Вывод

Программа печатает исходное поле, затем первое найденное решение и сообщает,
единственно ли оно. Если решений несколько, показывается первое, а в конце
выводится предупреждение.

Решение для примера:

```text
     #     #  -/10   -/2     #
     #   3/4     1     2     #
   7/-     3     4     #     #
   6/-     1     5     #     #
     #     #     #     #     #
```

## Запуск

```bash
javac -encoding UTF-8 -d out src/*.java
java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt
```

В PowerShell:

```powershell
cmd /c "java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt"
```

Можно вводить поле и вручную с клавиатуры: программа читает те же токены
из стандартного ввода.

## Идея решения

Используется рекурсивный перебор с возвратом. На каждом шаге выбирается первая
пустая белая клетка, в неё по очереди пробуются цифры от 1 до 9. Цифра
отбрасывается, если она уже есть в горизонтальном или вертикальном отрезке,
если частичная сумма превышает подсказку или если оставшуюся сумму нельзя
набрать оставшимся количеством различных цифр.

Для каждой белой клетки заранее находятся границы её отрезков и суммы, которые
должны получиться. Готовое поле дополнительно проверяется целиком.

Готовые коллекции JDK (`ArrayList`, `HashMap` и т. п.) не используются: только
массивы, рекурсия и обычные циклы.
