# Лабораторная работа №4

## Задача 1. Рекурсия. N-деревья

Дано N-дерево. Удалить самые далёкие от корня листья.

Дерево хранится через ссылки `firstChild` и `nextSibling`: у каждой вершины
есть первый ребёнок и следующий брат. Готовые коллекции JDK не используются.

## Ввод

Сначала `N`, затем `N` строк вида `значение parent`.
`parent` — номер родительской вершины (`0` для корня).
Порядок строк задаёт порядок детей.

```text
8
1 0
2 1
3 1
4 2
5 2
6 3
7 6
8 6
```

В этом примере листья `4`, `5`, `7`, `8`; самые далёкие из них — `7` и `8`
(глубина 4). После удаления останутся `4` и `5`.

## Запуск

```bash
javac -encoding UTF-8 -d out src/*.java
java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt
```

В PowerShell:

```powershell
cmd /c "java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt"
```

## Идея решения

Сначала рекурсивно вычисляется максимальная глубина дерева. Затем выполняется
второй рекурсивный обход: если ребёнок является листом и находится на
максимальной глубине, он удаляется из списка детей. Остальные вершины
обрабатываются рекурсивно.
