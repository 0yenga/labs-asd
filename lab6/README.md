# Лабораторная работа №6

## Задача 1. Методы сортировки

Имеется `N` камней с весами `A1, A2, ..., AN`. Нужно разбить их на две кучи
так, чтобы веса куч отличались не более чем в 2 раза. Если это невозможно,
программа должна сообщить об этом.

## Ввод

Сначала `N`, затем `N` положительных целых весов.

```text
7
1 3 2 5 3 4 2
```

## Запуск

```bash
javac -encoding UTF-8 -d out src/*.java
java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt
```

В PowerShell:

```powershell
cmd /c "java -Dfile.encoding=UTF-8 -Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main < input.txt"
```

## Идея решения

Пусть `S` — суммарный вес. Если одна куча имеет вес `x`, вторая имеет вес
`S - x`. Условие «отличаются не более чем в 2 раза» выполняется тогда и только
тогда, когда `S/3 <= x <= S/2` (для `x <= S/2`).

Сначала веса сортируются по убыванию сортировкой выбором. Затем точным
динамическим программированием (задача о подмножествах) проверяется, какая
сумма из диапазона `[S/3, S/2]` достижима. Восстановление набора камней
выполняется по массиву `lastIndex`.

Готовые коллекции и готовые алгоритмы сортировки JDK не используются.

Ограничение: точное динамическое программирование требует массива размера
`S + 1`, поэтому при суммарном весе больше `5 000 000` программа сообщает,
что не может решить задачу этим способом. Для лабораторных примеров этого
достаточно.
