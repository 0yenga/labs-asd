# Русские шашки

Учебный проект на Java Swing: русские шашки с компьютерным соперником.

## Возможности

- игра против компьютера (три уровня сложности) или вдвоём на одном компьютере;
- отмена хода и новая партия;
- подсветка выбранной шашки, допустимых ходов и последнего хода;
- управление мышью и клавиатурой;
- ИИ на основе минимакса с альфа-бета отсечением.

## Запуск

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```

Требуется JDK 17 или новее.
